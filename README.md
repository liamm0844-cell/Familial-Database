The Familial Database

All too often we meet new people and we have to take down their core details, The Familial Database solves this by centralising the experience into a single, easy to use package.

# Features

- A login screen to ensure secure access to the database.

- A menu to navigate the system.

- A button to see personal records and a button to see the records of the rest of your family.

- A button to add a new member of the database.

# Prerequisites

- **Java Development Kit (JDK):** Version 11 or higher
- **SQLite JDBC Driver:** Required to connect to familyDetail.db

# How to install

- Download the latest version on github.

- familialDatabase.java is the main file, whilst Extras.java has extra functions that are frequently used. The system is intended to be used with familyDetail.db.

- Open all files with an IDE of your choosing. For example Visual Studio Code.
